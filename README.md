Rainline is a rainy-night getaway in Port Vane: Rook, getaway driver for fixer Vera, runs four story jobs across a downpour downtown — by car and on foot, drifting rain-slick roads and outrunning the PVPD dragnet on the elevated expressway.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in your browser.
